# Python-for-Cybersecurity-Capstone-Project-Defensive-Threat-Detection-

This project is a Python-based cybersecurity capstone focused on **defensive security and multi-factor authentication (MFA)**. The program demonstrates how multiple authentication methods can be used to verify a user's identity before granting access.

## Authentication Methods

The system uses three authentication factors:

Password Verification** – Uses SHA-256 hashing to verify the user's password.
TOTP Verification** – Generates a six-digit Time-Based One-Time Password using HMAC-SHA1.
Biometric Verification** – Simulates biometric authentication by hashing and comparing a biometric key.

All three authentication factors must be successfully verified for access to be granted.

## Technologies Used

Python
SHA-256
HMAC-SHA1
TOTP
Multi-Factor Authentication (MFA)
Python libraries: `hashlib`, `hmac`, `base64`, `struct`, and `time`

## Skills Demonstrated

This project provided hands-on experience with Python programming, authentication, hashing, cryptographic concepts, user input, and defensive cybersecurity techniques.
